# Шпаргалка: i3, tmux, Vim и консольные инструменты

## Обозначения

- `Super` — клавиша с логотипом Windows (`Mod4` в конфигурации i3).
- `Prefix` — префикс tmux: `Ctrl+A`. Сначала нажать `Ctrl+A`, отпустить,
  затем нажать следующую клавишу.
- `Shift`, `Ctrl` и `Alt` нажимаются одновременно с указанной клавишей.

`Enter`, `Escape` либо `Super+R`.

### Рабочие столы

- `Super+1…0` — перейти на рабочий стол 1…10.
- `Super+Shift+1…0` — перенести активное окно на рабочий стол 1…10.

Громкость регулируется аппаратными мультимедийными клавишами. Раскладка
переключается через `Alt+Shift`.

## tmux

### Сессии

```bash
tmux                         # новая сессия
tmux new -s work             # новая именованная сессия
tmux ls                      # список сессий
tmux attach -t work          # подключиться к сессии
tmux kill-session -t work    # завершить сессию
```

| Клавиши | Действие |
| --- | --- |
| `Prefix d` | Отсоединиться от сессии |
| `Prefix s` | Интерактивный список сессий |
| `Prefix $` | Переименовать сессию |
| `Prefix r` | Перечитать `~/.tmux.conf` |
| `Prefix Ctrl+a` | Передать `Ctrl+A` программе внутри tmux |

### Окна и панели

| Клавиши | Действие |
| --- | --- |
| `Prefix c` | Создать окно в текущем каталоге |
| `Prefix n` / `Prefix p` | Следующее / предыдущее окно |
| `Prefix 1…9` | Перейти к окну по номеру |
| `Prefix ,` | Переименовать окно |
| `Prefix &` | Закрыть окно с подтверждением |
| `Prefix \|` | Разделить панель по горизонтали |
| `Prefix -` | Разделить панель по вертикали |
| `Prefix h/j/k/l` | Перейти к соседней панели |
| `Prefix H/J/K/L` | Изменить размер панели на 5 ячеек |
| `Prefix x` | Закрыть панель с подтверждением |
| `Prefix z` | Развернуть панель / вернуть обратно |

Мышь включена: панели можно выбирать и изменять их размер мышью, а окна —
выбирать в строке состояния.

### Копирование и логи

1. Нажать `Prefix [` для режима копирования.
2. Перемещаться клавишами Vim или стрелками.
3. Нажать `v`, чтобы начать выделение (`Ctrl+V` — прямоугольное).
4. Нажать `y`, чтобы скопировать и выйти.

Вывод каждой панели автоматически дописывается в отдельный файл в `~/log/`.

## Git и работа с репозиториями

### Git

```bash
git status                  # состояние рабочего дерева
git diff                    # незаписанные изменения; вывод оформляет delta
git diff --staged           # изменения, добавленные в index
git add <файл>              # добавить файл в index
git commit -m "сообщение"   # создать коммит
git log --oneline --graph --decorate --all
git switch <ветка>          # перейти на ветку
git switch -c <ветка>       # создать ветку и перейти на неё
git pull                    # только fast-forward согласно конфигурации
git fetch --prune           # обновить ссылки и убрать исчезнувшие ветки
```

`delta` автоматически используется Git для diff. В длинном diff клавиши `n`
и `N` переходят между изменёнными файлами; выход из pager — `q`.

### lazygit

```bash
lazygit
```

- `Tab` / `Shift+Tab` — перейти между панелями.
- Стрелки или `J/K` — навигация.
- `Space` — добавить/убрать файл или блок из index.
- `c` — создать коммит, `P` — push, `p` — pull.
- `?` — подсказка для текущей панели, `q` — выход.

## Навигация, поиск и просмотр

### Bash, ble.sh и fzf

- `Tab` — контекстное дополнение; повторное нажатие показывает варианты.
- `↑` / `↓` — история команд.
- `Ctrl+R` — интерактивный поиск по истории через `fzf`.
- `Ctrl+T` — вставить найденный путь в командную строку.
- `Alt+C` — перейти в найденный каталог.
- `Ctrl+C` — отменить ввод, `Ctrl+L` — очистить экран.

`ble.sh` также подсвечивает корректность команды и предлагает продолжение из
истории. Подсказку можно принять стрелкой вправо или `Ctrl+F`.

### zoxide

В этой конфигурации `zoxide` подключён вместо обычного `cd`:

```bash
cd proj                     # перейти в наиболее подходящий знакомый каталог
cd ~/git/nixconf            # обычный точный путь тоже работает
cdi                         # интерактивно выбрать каталог через fzf
zoxide query proj           # показать найденный путь
zoxide query -l             # список известных каталогов по рейтингу
```

### fd и ripgrep

```bash
fd console                  # найти файлы/каталоги по имени
fd -e nix                   # найти все файлы .nix
fd -H pattern               # учитывать скрытые файлы
rg 'codex|claude'           # найти текст рекурсивно
rg -n TODO modules home     # искать с номерами строк в каталогах
rg -g '*.nix' package       # ограничить поиск glob-шаблоном
rg --hidden pattern         # учитывать скрытые файлы
```

### bat

```bash
bat file.nix                # файл с подсветкой и номерами строк
bat -n file                 # без служебных рамок, но с номерами
bat -p file                 # простой вывод без рамок и нумерации
bat -A file                 # показать непечатаемые символы
```

## Окружения проектов

### direnv и nix-direnv

В каталоге проекта создать `.envrc`, например:

```bash
use flake
```

Затем разрешить его выполнение:

```bash
direnv allow
direnv status
direnv reload
```

При изменении `.envrc` потребуется снова выполнить `direnv allow`. Окружение
активируется при входе в каталог и автоматически выгружается при выходе.

## Starship

Starship запускается автоматически и показывает контекст текущего каталога:
Git-ветку и состояние репозитория, активное окружение и статус последней
команды. Проверка конфигурации и пояснение текущего prompt:

```bash
starship explain
starship timings
```

## Vim

### Запуск и базовые режимы

```bash
vim file.nix               # открыть файл
vim .                      # открыть текущий каталог
vim +42 file               # открыть файл на строке 42
vim -O file1 file2         # открыть два файла в вертикальных окнах
vim -d file1 file2         # сравнить два файла
```

- `i` — режим вставки перед курсором.
- `a` — режим вставки после курсора.
- `o` / `O` — новая строка ниже / выше.
- `Esc` — вернуться в normal mode.
- `v` — выделение, `V` — выделение целых строк.
- `u` — отменить действие, `Ctrl+R` — повторить отменённое.
- `.` — повторить последнее изменение.
- `yy` — скопировать строку, `dd` — удалить строку, `p` — вставить.
- `ciw` — заменить слово, `cw` — заменить до конца слова.

В конфигурации `Leader` — пробел. Например, `Space w` означает: нажать пробел,
затем `w`.

### Файлы, буферы и окна

| Клавиши | Действие |
| --- | --- |
| `Ctrl+N` | Открыть или закрыть NERDTree |
| `Space nf` | Найти текущий файл в NERDTree |
| `Space ff` | Найти файл через FZF |
| `Space fg` | Найти текст в проекте через ripgrep |
| `Space fb` | Переключиться на открытый буфер |
| `Ctrl+H/J/K/L` | Перейти в соседнее окно |
| `:split file` | Открыть файл в горизонтальном окне |
| `:vsplit file` | Открыть файл в вертикальном окне |
| `:bnext` / `:bprevious` | Следующий / предыдущий буфер |
| `:bdelete` | Закрыть текущий буфер |

В NERDTree: `Enter` открывает файл или каталог, `s` открывает файл в
вертикальном окне, `i` — в горизонтальном, `m` показывает меню файловых
операций, `q` закрывает дерево, `?` показывает справку.

### Автодополнение и навигация по коду

Автодополнение обеспечивает Coc. Для Python подключён Pyright, также включена
поддержка JSON и YAML.

| Клавиши | Действие |
| --- | --- |
| `Tab` / `Shift+Tab` | Следующий / предыдущий вариант дополнения |
| `Enter` | Принять выбранное дополнение |
| `gd` | Перейти к определению |
| `gy` | Перейти к определению типа |
| `gi` | Перейти к реализации |
| `gr` | Найти использования символа |
| `K` | Показать документацию |
| `[g` / `]g` | Предыдущая / следующая диагностика |
| `Space rn` | Переименовать символ в проекте |
| `Space ca` | Доступные действия над кодом |
| `:CocInfo` | Состояние Coc и языковых серверов |
| `:CocList diagnostics` | Список ошибок и предупреждений |

### Git внутри Vim

| Клавиши | Действие |
| --- | --- |
| `Space gp` | Открыть Git status через Fugitive |
| `Space hn` / `Space hp` | Следующее / предыдущее изменение |
| `Space hs` | Добавить текущий блок изменений в index |
| `Space hu` | Отменить текущий блок изменений |
| `:Gdiffsplit` | Сравнить файл с версией в Git |
| `:Git blame` | Показать авторов строк |
| `:Git commit` | Создать коммит |

Изменённые строки отображаются знаками слева. В Lightline внизу видны режим,
Git-ветка, имя и состояние файла, диагностика Coc, тип файла и позиция курсора.

### Полезные плагины

- `gcc` — закомментировать или раскомментировать строку.
- `gc` после выделения — изменить комментарий у выделенного блока.
- `ysiw"` — окружить слово двойными кавычками.
- `cs"'` — заменить двойные кавычки на одинарные.
- `ds"` — удалить окружающие двойные кавычки.
- Скобки и кавычки автоматически закрываются благодаря Auto Pairs.
- История отмены сохраняется между запусками Vim в `~/.vim/undo/`.
